نمودار معماری پروژه — «صدا به درایو»

همان نمودارهای ARCHITECTURE.md، اینجا با mermaid رسم می‌شوند. اگر مرورگر به CDN دسترسی نداشت، متن نمودارها را از همان فایل بردارید و در mermaid.live پیست کنید.

کتابخانهٔ mermaid از CDN بارگذاری نشد (احتمالاً بدون اینترنت). متن هر نمودار در فایل ARCHITECTURE.md موجود است و می‌توانید آن را در mermaid.live یا VS Code رندر کنید.

stateDiagram-v2
    [*] --> PENDING: پایان ضبط یا انتخاب فایل
    PENDING --> COMPRESSING: enqueueCompression
    COMPRESSING --> UPLOADING: FFmpeg موفق
    UPLOADING --> COMPLETED: آپلود موفق

    PENDING --> UPLOADING: Retry وقتی فایل mp3 است
    COMPLETED --> [*]: پاک کردن آپلودهای تمام‌شده
